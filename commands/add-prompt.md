---
description: Add a new favorite prompt to prompt-shortcut — asks for name/description/body and saves it so it appears in the menu
---

Invoke the **prompt-shortcut** skill (use the Skill tool) and run its **add-prompt** workflow: interactively collect a new prompt (name, title, description, body, and whether to make a direct `/<name>` shortcut) and save it into the skill's `prompts/` folder so it auto-appears in the `/prompt-shortcut` menu. Do not show the regular menu.
